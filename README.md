# Glyphtone

**[Live demo →](https://acgourley.github.io/glyphtone/)**

A halftone made of glyphs. Renders images with proportional fonts, picking each character by its width and ink density.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build      # outputs to ./dist
```

Drop an image into the preview pane (or paste from clipboard) and tweak the controls. Settings persist across reloads.
